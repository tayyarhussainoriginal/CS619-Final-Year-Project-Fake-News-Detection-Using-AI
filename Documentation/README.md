
# Project Documentation

This directory contains the final academic documentation for the **Fake News Detection Using AI** project, developed as part of the CS619 Final Year Project.

## Documents

### 1. Final Project Report
The complete project report covering the problem statement, requirements analysis, system design, methodology, implementation, machine learning approach, testing, evaluation, challenges, and future enhancements.

### 2. Final Presentation
The final presentation summarizing the project's objectives, system architecture, key features, machine learning methodology, implementation, and evaluation results.

### 3. Supporting University Document
Additional university-related documentation associated with the CS619 final-year project submission including SRS, Design Document and Problem Statement.

## Project Overview

The project implements a Django-based web application that uses Natural Language Processing (NLP), TF-IDF feature extraction, and Logistic Regression to classify submitted news text as Real or Fake.

The final report documents the methodology and reported model evaluation results.

- **Application:** Django web interface and trained model files.
